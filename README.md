# Sistema de calificaciones con arreglos 

## Descripción 
Programa desarrollado en Python para almacenar y analizar las calificaciones de cinco estudiantes mediante un arreglo unidimensional. 

## Objetivo 
Aplicar arreglos, índices, ciclos, condiciones y operaciones de cálculo en la solución de un problema académico. 

## Lenguaje utilizado 
Python 3. 

## Funcionalidades 
- Mostrar todas las calificaciones. 
- Consultar una calificación mediante su índice. 
- Calcular el promedio. 
- Encontrar la calificación más alta. 
- Encontrar la calificación más baja. 
- Contar estudiantes aprobados y reprobados. 
- Modificar una calificación. 
- Mostrar el vector actualizado. 

## Instrucciones de ejecución 
1. Instalar Python 3. 
2. Descargar o clonar este repositorio. 
3. Abrir una terminal en la carpeta del proyecto. 
4. Ejecutar el siguiente comando: 
```bash 
python sistema_calificaciones.py
